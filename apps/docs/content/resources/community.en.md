# Community

We welcome improvements to documentation, tokens, components and accessibility.

1. Use the page footer to report an issue. Include reproduction steps, the page language, and expected and actual behavior.
2. Work on a repository branch you can access. Update the source and both document languages, and record the origin and license of any new assets.
3. Run token validation, type checks, the build and browser tests. Include evidence of light, dark and keyboard testing for UI changes.
4. Open a pull request with the preview link and tested commit for maintainer review.

See the [contribution guide](https://github.com/devcgp/macos-components-react/blob/main/CONTRIBUTING.md).
